# Z Potentials英文访谈文章编译

团队分享版1.0.0。只用于把英文访谈视频、播客或逐字稿编译为中文深度访谈文章；不用于Z Wave人物稿、Product稿、英文博客改写或一般原创文章。

## 能完成什么

核对英文原文，逐句翻译和口语整理，按深度SOP排版，配置一张封面和至少四张正文图，经授权实际交豆包全文审查，最终交付三份Word：英文原稿、中英对照稿、中文成品稿。提供三个候选标题及原视频标题译文。局部返修只交修改稿，并逐项报告修改。

这是供AI按步骤执行的工作规范，不是独立的一键翻译软件。检索、登录、文档生成和逐页渲染依赖使用者当前环境；无法取得原稿、无法审核或无法渲染时必须明确报告，不得虚报完成。

## 安装与调用

分享整个`zpotentials-depth-interview`文件夹，不只分享SKILL.md。同事可在Codex中说：“请把我提供的Skill文件夹安装到个人技能目录，保留完整目录结构，不覆盖同名文件。”

按当前官方文档，团队项目目录可用`.agents/skills/zpotentials-depth-interview/`，跨项目个人目录可用`~/.agents/skills/zpotentials-depth-interview/`。已有安装在`~/.codex/skills/`且可用的旧环境无需强制搬动。不要在多个目录安装同名副本，避免选择混淆；更新前备份个人配置。安装后在技能列表检查，未出现再重新打开Codex。

官方安装与结构说明：https://learn.chatgpt.com/docs/build-skills

调用示例：

```text
请使用$zpotentials-depth-interview编译这期英文访谈。
视频链接：……
编译署名：本期实际作者姓名
输出目录：本次工作区中的访谈项目
允许将本期拟发布的完整中文稿提交豆包审查。
```

只有链接时先找英文稿；全文不可用则说明缺口，由作者提供文字或有权使用的素材。新同事不需要读过去的聊天。

## 个人设置

本包默认不填姓名。可让Codex将`profile.example.json`复制为`profile.local.json`，把`compiler`设为本人已确认的署名，也可每次任务直接提供姓名。本地文件不要提交到公共仓库或打进分享包。

署名优先级：本次明确指定 > 项目配置 > 个人本地配置。`--compiler`是直接指定，`--profile`指定项目配置文件；没有指定项目配置才读取可选的本地配置。个人配置目前只支持`compiler`，不接受其他键。品牌声明保持团队原文，不把姓名替换成随机默认值。

```json
{
  "compiler": "本期已确认的实际署名"
}
```

## 任务中何时需要人介入

- 完整英文文本缺失、内容授权不足，或关键原音无法核对，需补素材或确认取舍。
- 缺少署名、遇到登录或验证码，需作者提供信息或自行操作。
- 没有外部审查授权，需先确认再把全文发给豆包。
- 三个标题可以最后选择；未选择不妨碍翻译和排版。
- 审查发现问题、图片许可不明或翻译有实质歧义时，给出具体位置供作者判断，不自动删大段内容。

## 文件职责与修改方法

- `SKILL.md`：AI入口、适用边界、阶段与输出要求。
- `references/depth-sop.md`：文章结构、翻译、配图、格式与文末规范。
- `references/rules.json`：篇幅、图片数量、字体等机器可读团队默认值。
- `references/footer.txt`：品牌声明和署名模板，仅替换`{compiler}`。
- `references/experience/*.md`：六阶段的短经验清单，每阶段完成后按需读取。
- `references/delivery-and-review.md`：审查证据、版本哈希和验收方式。
- `scripts/`：配置解析、静态验收与模拟测试，不负责自动下载或浏览器登录。

修改团队规则后，同步相关参数和检查器，再执行测试。单篇文章的临时例外只记入该项目QA，不轻易改公共标准。共享经验由维护者合并；普通使用者先提交候选，不默认改团队文件。

## 工具与验证

脚本需要Python3.10以上，验收依赖`python-docx>=1.2.0`；模拟测试还需Pillow。优先使用宿主提供的运行时和包，缺少时先确认环境，不硬编码同事电脑的路径。联网工具、文档生成/批注工具、实际页面渲染工具和豆包访问另由当前环境提供，不包含在ZIP中。

在Skill目录运行，`<python>`替换为当前环境实际解释器：

```text
<python> scripts/skill_config.py --compiler "本期实际署名" --footer
<python> scripts/lint_experience.py
<python> scripts/test_audit.py
<python> scripts/audit_delivery.py --english <英文.docx> --bilingual <双语.docx> --final <成品.docx> --compiler "本期实际署名" --evidence <review-evidence.json>
```

检查脚本通过不代表翻译准确、真实执行了豆包审查或页面美观；内容核对、实际审查与逐页看图都必须另行完成。缺任何必要验收就交付为部分完成，列出待办。

## 分享与版本维护

对外分享ZIP只含本Skill文件，不含`profile.local.json`、账号、浏览器会话、历史访谈稿、内部批注、缓存或个人磁盘路径。版本号维护在rules.json。修改后用同一目录重新打包，并向同事说明是否改变署名配置或验收接口。

修改已安装Skill不会自动更新GitHub或旧ZIP。发布需另行确认，将验证过的公共文件同步到仓库后提交并推送；同事已安装的独立副本也需自行更新。不要把个人配置、项目材料或内部批注一起上传；本流程不默认自动推送。

未来人物写作、Product稿和英文博客编译各建独立Skill；共享规则成熟后再考虑抽取，不提前拼成一个万能Skill。当前技术标识保留为`zpotentials-depth-interview`，兼容既有调用。
